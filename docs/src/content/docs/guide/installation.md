## Requirements

- Craft CMS 5.8.0 or later
- PHP 8.2 or later

## Install

Install the plugin from the [**Plugin Store**](https://plugins.craftcms.com/stack) in the Control Panel, or with [Composer](https://packagist.org/packages/somehow-digital/craft-stack):

```bash
composer require somehow-digital/craft-stack
php craft plugin/install stack
```

:::note
The plugin works for frontend templates only. Control Panel templates aren't affected.
:::
